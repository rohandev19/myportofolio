## Why Generics Matter

Generics are the cornerstone of reusable TypeScript code. They allow you to write functions and components that work with any data type while maintaining full type safety.

## Generic Components in React

### A Type-Safe List Component

```tsx
interface ListProps<T> {
  items: T[];
  renderItem: (item: T, index: number) => React.ReactNode;
  keyExtractor: (item: T) => string;
  emptyMessage?: string;
}

function List<T>({ items, renderItem, keyExtractor, emptyMessage }: ListProps<T>) {
  if (items.length === 0) {
    return <p className="text-slate-400">{emptyMessage || 'No items'}</p>;
  }

  return (
    <ul>
      {items.map((item, index) => (
        <li key={keyExtractor(item)}>{renderItem(item, index)}</li>
      ))}
    </ul>
  );
}
```

### Generic Data Fetching Hook

```typescript
function useQuery<T>(url: string): {
  data: T | null;
  loading: boolean;
  error: Error | null;
} {
  const [data, setData] = useState<T | null>(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState<Error | null>(null);

  useEffect(() => {
    fetch(url)
      .then(res => res.json())
      .then((result: T) => setData(result))
      .catch(setError)
      .finally(() => setLoading(false));
  }, [url]);

  return { data, loading, error };
}
```

## Constraint Patterns

### Ensuring Object Shape

Use `extends` to constrain generic types:

```typescript
function getProperty<T extends Record<string, unknown>, K extends keyof T>(
  obj: T,
  key: K
): T[K] {
  return obj[key];
}
```

### Conditional Types

Build powerful type transformations:

```typescript
type ApiResponse<T> = T extends Array<infer U>
  ? { items: U[]; total: number }
  : { data: T };
```

## Best Practices

1. **Name generics descriptively** — Use `TItem` instead of just `T` for clarity
2. **Default generic parameters** — Provide defaults when sensible
3. **Constrain when possible** — Use `extends` to narrow types
4. **Document complex generics** — Add JSDoc for team readability

## Conclusion

TypeScript generics unlock the full potential of reusable, type-safe code. Start with simple generic functions, then graduate to generic components and hooks as your confidence grows.
